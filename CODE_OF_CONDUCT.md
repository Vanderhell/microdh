# Code of Conduct

## Our standard

Be respectful, be constructive, and assume good faith.

## Expected behavior

- Use clear, professional language.
- Focus on the code, documentation, and evidence.
- Give actionable feedback and accept corrections in the same spirit.

## Unacceptable behavior

- Harassment or abuse.
- Personal attacks.
- Deliberate disruption.
- Publishing private information without consent.

## Enforcement

Maintainers may remove content or block participation when behavior makes collaboration unsafe or unproductive.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and related project spaces.
